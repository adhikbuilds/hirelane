# JSON-LD / Zoho fixtures

Hand-authored from the schema.org `JobPosting` documentation and Google's job-posting structured-data guide,
using the fictional host `careers.trelliscloud.in` (Trellis Cloud). They are NOT recordings of a live site:
no real employer's pages are stored in the repo. Replace or extend them with real recordings only after a host
is on the allowlist (`source.allowlist.json`) with a dated robots/terms note.
